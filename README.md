# cybersecurity-home-lab

Building a professional cybersecurity home lab using VMware, Ubuntu, Windows, networking, and Wazuh and documenting everything I learn.

## Overview

This repository documents my journey learning IT and cybersecurity from the ground up.

I am building a professional home lab using VMware Workstation Pro. Every major step is documented with notes, screenshots, and lessons learned.

## Goals

- Learn Linux administration
- Learn Windows administration
- Understand networking fundamentals
- Build a Security Operations Center (SOC) lab
- Deploy Wazuh SIEM
- Investigate security alerts
- Document everything professionally

## Why I Built This

I wanted to understand cybersecurity by building and documenting a realistic home lab to have a more hands on experience. This repository serves as both my learning journal and professional portfolio.
